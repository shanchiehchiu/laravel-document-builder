# 設計器元件面板：待辦

來源：對元件面板的 UI 審查。下列項目已對照 `resources/dist/designer.js` 與 GrapesJS 樣式確認，狀態標註為「已確認」者表示問題存在。

## 一、圖示變成實心黑塊（高優先）

- [x] **已確認**：GrapesJS 的 `.gjs-block svg{fill:currentColor}` 會蓋過 `icon()` 的 `fill="none"` 屬性，子元素繼承後變成實心。
- 做法：在設計器樣式中，把 `#wfb-blocks svg { fill: none; }` 與 `#wfb-blocks svg * { fill: none; }` 限定在元件面板內，避免影響其他區域。

## 二、圖示語意化

- [x] 為常用主檔來源補上獨立圖示（使用者：頭像；員工：識別證；請假紀錄：日曆加時鐘）。

## 四、補齊業務元件（依優先序）

- [x] **金額／貨幣**（已完成）：欄位型別 `amount`，屬性為小數位（預設 2）與幣別符號（選填）。
  - 存檔規範：送出與儲存的一律是純數值，千分位與幣別只在顯示層。伺服器與數字欄位相同，存檔時四捨五入到小數位。
  - 填單頁：可見的輸入框沒有 `name`，不會被送出；真正送出的是旁邊的隱藏欄位（`data-amount-raw`，內容為純數字）。獲得焦點時顯示純數字，離開時補上千分位並四捨五入到小數位；事件引擎讀取時回傳數字。
  - 唯讀（檢視）模式：隱藏欄位停用時，顯示框也會停用。
  - 設計器：面板圖示、畫布預覽（含幣別）、小數位與幣別屬性、事件值以數字輸入。
  - 驗證：`tests/Feature/AmountFieldTest.php`（3 項）；`amount-field.js` 以 headless Chrome 驗證 12/12 項（輸入、焦點、離開、非數字過濾、四捨五入、程式改值、事件觸發、唯讀）。
  - 決定：「欄位」3+3+2 維持原狀（左對齊、保留最後一格空白），不做跨欄。理由：複選加入後會變成 3×3 滿格；針對 3n+2 寫跨欄 CSS 會留下要拆除的技術債。
- [ ] **計算／公式**：與待辦中的「換算組」與「伺服器端重算」相關，應一併設計，不要各自實作。
- [x] **單選按鈕組**（已完成）：欄位型別 `radio`，與固定選項共用 `choices`，多一個「排列方向」（水平／垂直，預設水平）。
  - 後端：`config/form_platform.php` 型別定義（`layout` 為列舉）、`DocFieldService` 驗證與儲存、`RecordValidator` 只接受選項中的值、事件值驗證、版面與 schema 轉換、文件來源文字型別。
  - 填單頁：未選時送出空字串（與勾選框相同作法）；非必填的單選可以取消（再點一次已選的選項就清空，會通知事件引擎）；必填的單選不能取消。
  - 設計器：面板圖示、畫布預覽、選項與排列方向屬性、事件值下拉。
  - 驗證：`tests/Feature/RadioFieldTest.php`（4 項）；前端以 headless Chrome 驗證有無 jQuery 兩種路徑，各 9/9 通過；真實設計器面板與畫布預覽截圖確認。
  - 限制：取消功能只支援滑鼠點擊，鍵盤無法清空已選的單選。
- [x] **複選標籤組**（已完成）：欄位型別 `checkgroup`，與固定選項共用 `choices`，多一個「排列方向」（水平／垂直，預設水平）。複選後「欄位」分類正好 9 張（3×3 滿格）。

## 五、排版與互動

- [x] 卡片文字過長時加上 `text-overflow: ellipsis`；完整名稱由 GrapesJS 預設的 `title` 提供（已確認，不需另外設定）。
- [x] 卡片 hover 時顯示 `cursor: grab`（拖曳中為 `grabbing`）。
- [x] 拖曳把手紋路：卡片右上角六點圖示（CSS `::before` 實作，平時淡化、hover 加深）。
- [x] 水平卡片版型＋單張卡片跨欄：分類裡只有一張積木時（目前是主檔關聯、明細表），卡片跨滿整列，改成圖示左、文字右，避免 3 欄網格留下空格。
  - 問題來源（真實設計器截圖與 DOM 量測）：面板為 3 欄 CSS Grid，各分類積木數為欄位 6、主檔下拉 1、輔助排版 3、表格 1，主檔下拉與表格右側各空 2 格。
  - 實作只改 CSS，DOM 結構不變；鏈結標記在水平版型下改到左下角，避免和圖示重疊。
  - 規則已泛化為 `:nth-child(3n+1):last-child`：分類最後一張若剛好是新排的第一格（例如「輔助排版」加入分隔線後變成 4 張），就跨滿整列。目前「輔助排版」第 4 張是「空白格」，會以水平卡片呈現。
  - 驗證：真實設計器頁面重新截圖，兩個單張分類已跨欄並靠左對齊，其他分類不受影響。
  - 注意：這個規則只對「分類裡唯一的一張積木」生效。之後若主檔下拉或表格加入第二張積木，會自動回到 3 欄直式卡片。
- [x] 已封存分類的「折疊計數標籤」：已實作。分類標題為「已封存（N）」，N 為封存的欄位與明細表數量（`designer.js` 的 `archivedLabel`），分類可摺疊。原先這一項被標為未實作，是文件錯誤，已更正。
